## Choose a folder first

The App Store edition requires a native folder choice before scanning. Access lasts for the current app session. Choose the folder again after relaunch. Quick Review shares the chosen folder with Duplicates, Large & Old Files and Storage Map. Application inventory has a separate folder choice.

## No files appear

Check the chosen folder and your filters. Large & Old Files defaults to 100 MB or larger; its minimum option is 10 MB. Hidden files, bundles, empty files, symlinks and hard links are excluded from the file inventory. Date filters use the last-modified date, not the last time you opened a file.

## A scan reports an error

Open View Report after Quick Review for the affected area's scope and error. Confirm that the folder remains available, then choose it again or rescan. Avoid disconnecting an external drive during scanning. Other completed areas remain useful if one scan fails.

## Removing files and recovering them

Scanning never removes files. File and duplicate removal shows a review sheet first, including selections hidden by filters. Confirming moves selected files to Finder Trash. Restore them in Finder before you empty Trash. StorageFix does not automatically empty Trash. If a file changes after scanning, rescan before removal.

## Reports and privacy

View Report shows a snapshot from the completed review. Exported reports include scope paths, counts, sizes and any scan errors, but no scanned file contents. Review a report before sending it to support. File and duplicate inventories overlap; do not add their sizes to estimate recoverable space.

## Applications and Safety Check

Application inventory is read-only in the App Store edition. Safety Check records your own checklist choices and opens macOS settings. It does not detect malware or verify security configuration. System-cache cleanup and application uninstalling are not included.

## Local preferences

Clear History removes recent activity. Reset Checklist clears the personal checklist. Reports are not retained across relaunches unless you export them. Uninstalling may leave preferences managed by macOS.

## When contacting support

Include your StorageFix version, macOS version, the affected screen and the exact error message. Do not send personal files or unreviewed reports. A screenshot with personal paths redacted is usually sufficient.
