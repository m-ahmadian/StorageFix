## Signing

This Mac exposes an Apple Development identity. App Store distribution and installer identities and a Mac App Store provisioning profile were not found during this audit. An Apple Development certificate cannot sign the submission.

Install the Mac App Store distribution app/installer certificates with private keys and download the explicit App ID's Mac App Store profile. Keep certificates and profiles outside source control. Do not share private keys or passwords in chat.

The existing packaging script accepts `SIGN_IDENTITY`, `APP_STORE_PROFILE` and `APP_STORE_INSTALLER_IDENTITY` as environment variables. `Scripts/package-store.sh` builds a universal Store app and, with these configured, creates a signed installer `.pkg`. Team-specific entitlements are derived from the profile. The script rejects missing profile/signer inputs and validates the resulting package locally.

Run `python3 Scripts/verify-store.py dist/AppStore/StorageFix.app --submission --package dist/AppStore/StorageFix.pkg` before Apple's upload validation. No notarization is needed for Mac App Store submission; the direct-download notarization path is separate.

## Reproduce local checks

```sh
python3 -m unittest discover -s Tests/PackagingTests -v
swift test --scratch-path /private/tmp/storagefix-release-tests
swift test --scratch-path /private/tmp/storagefix-store-ready -Xswiftc -DAPP_STORE --filter 'StoreReadinessTests|ReviewReportTests'
SIGN_IDENTITY=- NOTARY_PROFILE= APP_STORE_INSTALLER_IDENTITY= Scripts/package-store.sh
python3 Scripts/verify-store.py dist/AppStore/StorageFix.app
```

Screenshot candidates can be regenerated by setting `STORAGEFIX_STORE_SCREENSHOTS` to an existing absolute output directory and running `StoreScreenshotTests` in the APP_STORE test configuration.
